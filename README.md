# Expressive timing with rhythm categories and L-systems

Interactive demo accompanying *Generating expressive timing by combining
rhythmic categories and Lindenmayer systems* (Vaquero Patricio & Honing, AISB 2014).

**▶ Live demo: https://carlosvaquero.github.io/aisb2014-Generating_Expressive_Timing/**

A logo-turtle moves through approximated Desain & Honing's perceptual rhythm categories,
driven by L-system production rules, and generates expressive timing within a
four-onset bar. You can edit the axiom and rules, step through the path, and
hear the resulting onsets.

## Run locally
Open `index.html` in a browser. It loads React and KaTeX from CDNs, so it needs
an internet connection.

## Reference
Vaquero Patricio, C., & Honing, H. (2014). Generating expressive timing by
combining rhythmic categories and Lindenmayer systems. *AISB 2014.*
[https://doc.gold.ac.uk/aisb50/AISB50-S04/AISB50-S4-Patricio-paper.pdf]

Rhythm category data: Desain, P., & Honing, H. (2003). The formation of
rhythmic categories and metric priming. *Perception*, 32(3), 341–365.
